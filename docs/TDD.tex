\section{Introduction}
This document provides a comprehensive Technical Design Document for the Alien Invaders game implemented in Godot 4.x. The game is a Space Invaders-style 2D shooter featuring player-controlled spaceship mechanics, dynamic enemy AI with obstruction detection, power-up systems, scoring mechanics, and GUI elements. The architecture is built on singleton manager patterns for centralized state management and scene orchestration.

\section{System Architecture and Design}

\subsection{Architecture Overview}

Alien Invaders uses a hierarchical state management architecture centered around a GameManager singleton that coordinates all game systems:

\begin{itemize}
    \item \textbf{GameManager}: Central orchestrator managing game state, scene references, and system coordination
    \item \textbf{Player System}: CharacterBody2D-based player ship with movement, combat, power-ups, and health
    \item \textbf{Enemy System}: CharacterBody2D-based enemy ships with async AI shooting loops and obstruction detection
    \item \textbf{Enemy Parent}: Node2D-based group movement controller with timer-driven random grid shifts and tween animation
    \item \textbf{Score Manager}: Global singleton tracking accumulation, bonuses, and high score
    \item \textbf{Power-up System}: Manager and individual power-ups with collision detection and effect application
    \item \textbf{Scene Loader}: Backend system supporting both direct and threaded scene loading
    \item \textbf{GUI System}: Multi-layer UI including HUD, timers, end-game popups, and menus
    \item \textbf{Intro Splash}: Animated intro sequence with logo and icon fade transitions, skippable via input
    \item \textbf{Level Manager}: Scene-based level state tracking and timer management
\end{itemize}

\subsection{Core Design Patterns}

\textbf{Singleton Manager Pattern:}
All manager systems (GameManager, ScoreManager, PowerupManager, SceneLoader) are implemented as global autoloads, providing centralized access throughout the game.

\textbf{Hierarchical State Management:}
GameManager holds references to all major systems and is responsible for state transitions (game running, paused, won, lost).

\textbf{Async Coroutine-Based AI:}
Enemy shooting behavior implemented via GDScript coroutines (\_Engage()) for clean async loops without frame-by-frame polling.

\textbf{Physics-Based Movement:}
Player uses CharacterBody2D.move\_and\_slide() for screen-boundary respecting movement. Projectiles use direct position updates with Area2D collision detection.

\section{Game Features and Mechanics}

\subsection{Player Mechanics}
\begin{itemize}
    \item Player moves left/right within screen boundaries with sprite feedback (idle/left/right)
    \item Fires projectiles with configurable cooldown timer (can be bypassed with firerate power-up)
    \item Three active power-up types: firerate (rapid-fire), speed (2x movement), shield (damage negation)
    \item Power-ups display with visual progress bar and expire after specified duration
    \item Health system with 3-point default (can be modified per level)
    \item Game ends when player health reaches 0
\end{itemize}

\subsection{Enemy Mechanics}
\begin{itemize}
    \item Enemies positioned in grid layout with configurable row offsets
    \item Async shooting loop with probability-based (50\% default) and cooldown-based (1-4s) triggering
    \item RayCast2D node-based obstruction detection prevents shooting through other entities
    \item Group movement via EnemyParent: periodic random-direction shifts (4-way + diagonal) with smooth tween animation
    \item Power-ups drop with 10\% probability on enemy death
    \item Enemy death awards 100 points and decrements enemy counter
    \item All enemies defeated triggers win condition (finite mode) or next wave (infinite mode)
\end{itemize}

\subsection{Scoring System}
\begin{itemize}
    \item Enemy kills accumulate points (100 per enemy by default)
    \item Survival bonus (1000) awarded when level completed before timeout
    \item Time bonus calculated as percentage of expected level time (0-10000 points)
    \item Highest score tracked in-memory during session
    \item Score breakdown displayed in end-game popup
\end{itemize}

\subsection{Game State Management}
\begin{itemize}
    \item Pause system with time scale adjustment (0.1 for pause, 1.0 for normal)
    \item Game end displays popup with score breakdown and survival status
    \item Level timer counts down and triggers bonus loss visualization
    \item Win/loss states managed by GameManager with proper cleanup
    \item Main menu displays current highest score
\end{itemize}

\section{Implementation Details}

This section provides detailed technical documentation of each major game system, including their responsibilities, internal state, and interactions with other systems.

\subsection{Player Ship System}

\subsection{Constants and Configuration Values}

\subsubsection{Player Ship}
\begin{itemize}
    \item Default health: 3.0
    \item Movement speed: 300.0 pixels/second
    \item Sprite margin: 50 pixels from screen edges
    \item Fire cooldown: Configurable via Timer node (default 1.0s)
    \item Speed power-up multiplier: 2.0x
    \item Shooting direction: Vector2.UP
    \item Projectile spawn offset: 50 pixels in shooting direction
\end{itemize}

\subsubsection{Enemy Ship}
\begin{itemize}
    \item Default health: 1.0
    \item Shoot chance: 0.5 (50\%)
    \item Cooldown timer range: 1-4 seconds
    \item Power-up drop probability: 0.1 (10\%)
    \item Points per enemy: 100
    \item Time addition per enemy: 2.0 seconds
    \item Shooting direction: Vector2.DOWN
    \item Projectile spawn offset: 50 pixels in shooting direction
    \item RayCast2D node for obstruction detection (target\_position = Vector2(0, 60))
\end{itemize}

\subsubsection{Enemy Parent (Group Movement)}
\begin{itemize}
    \item Move step: row\_offset distance per movement
    \item Directional move limit: 2 steps from origin in any axis
    \item Move timer range: 2-4 seconds between shifts
    \item Movement types: single-direction (25\%) or diagonal (75\%)
    \item Tween duration: 1.0 second for smooth animated movement
\end{itemize}

\subsubsection{Projectile}
\begin{itemize}
    \item Default speed: 250 pixels/second
    \item Damage per projectile: 1.0
    \item Rotation offset: +90 degrees (deg\_to\_rad)
    \item Lifetime: Configured via Timer node (self-cleanup)
    \item Collision layer: Area2D with body\_entered detection
\end{itemize}

\subsubsection{Power-up}
\begin{itemize}
    \item Drop speed: 100 pixels/second
    \item Default duration: 2.0 seconds (shield power-up uses 5.0 seconds)
    \item Power types: ``firerate'', ``speed'', ``shield''
    \item Survival bonus: 1000 points
    \item Time bonus base: 10000 points
    \item Time bonus calculation: (time / expected\_time) * time\_bonus (0 to max\_int)
    \item Out-of-screen cleanup: VisibleOnScreenEnabler2D detects screen exit and frees power-up
\end{itemize}

\subsubsection{Game State}
\begin{itemize}
    \item Slowed time scale: 0.1 (for pause menu and end game)
    \item Normal time scale: 1.0
    \item Level timer: Starts with expected\_time calculated from all enemies
    \item Initial highest score: -1 (no score recorded)
\end{itemize}

\subsubsection{Enemy Manager Grid}
\begin{itemize}
    \item Row offset distance: Configurable (used for positioning and movement step)
    \item Placement markers: Configurable array (typical: 17 markers for 17 columns)
    \item Row wrapping: After len(enemy\_placements) enemies, increment row\_count
    \item Move Timer: One-shot timer triggering periodic group movement via EnemyParent
\end{itemize}

\subsection{Godot Engine Integration}

\begin{itemize}
    \item Engine version: Godot 4.x
    \item Primary scripting language: GDScript
    \item Physics: Built-in Godot physics with Area2D and CharacterBody2D
    \item Input system: InputMap-based actions (ui\_left, ui\_right, ui\_accept, ui\_up, Menu)
    \item Rendering: 2D CanvasLayer-based UI system with theme support
    \item Resource loading: Dual-mode (direct ResourceLoader and threaded queue system)
    \item Time control: Engine.time\_scale manipulation for pause/slow effects
    \item Collision detection: Raycast queries and Area2D body signals
    \item Groups: ``damageable'' for damage-receiving entities
    \item Singletons: PowerupManager (static Instance), GameManager, ScoreManager, SceneLoader
\end{itemize}

\subsection{Known Game Modes}

\begin{itemize}
    \item \textbf{Finite Level}: Level with timer-based win condition. Player must defeat all enemies before the timer expires. Level length determined by sum of all enemy time\_addition values plus configurable padding.
    \item \textbf{Infinite Level}: Fixed enemy wave with no timer-based win condition. Score accumulates indefinitely.
    \item Both modes share core mechanics (movement, combat, scoring, power-ups) but differ in win conditions and enemy spawning behavior.
\end{itemize}

\subsection{System Architecture and Interactions}

\subsubsection{Game Flow Overview}

The game follows a hierarchical state management pattern with GameManager as the central coordinator:

\begin{enumerate}
    \item \textbf{Initialization}: Scene loads with EnemyManager spawning enemies via EnemySpawner
    \item \textbf{Enemy Positioning}: Enemies placed in grid using EnemyManager's row offset calculations
    \item \textbf{Expected Time Calc}: EnemySpawner accumulates all enemy time\_addition values into Level.expected\_time
    \item \textbf{Gameplay Loop}: Player moves/shoots, enemies shoot with obstruction detection, powerups apply effects
    \item \textbf{Damage/Scoring}: Enemy takes damage, calls ScoreManager.add\_points(), then enemy\_manager.decrement\_enemy\_count()
    \item \textbf{End Conditions}: Win when all enemies dead, lose when player health $\leq$ 0. Timer expiry removes survival bonus.
    \item \textbf{End Game}: GameManager.game\_won() or game\_lost() triggers UI popup with calculated score
\end{enumerate}

\subsubsection{Player System Details}

The Player class is a CharacterBody2D with multiple interconnected systems:

\textbf{Movement System:}
\begin{itemize}
    \item Reads input via Input.get\_axis(``ui\_left'', ``ui\_right'') in \_physics\_process()
    \item Applies velocity = direction * SPEED * speed\_mult
    \item Uses move\_and\_slide() for physics-based movement
    \item Clamps position to screen boundaries using viewport rect
    \item Sprite feedback shows idle/left/right visual based on direction
\end{itemize}

\textbf{Combat System:}
\begin{itemize}
    \item Shooting triggered by ui\_accept or ui\_up input in \_input()
    \item Can fire if can\_fire flag true OR firerate\_up power active
    \item Projectile instantiated from exported PackedScene
    \item Projectile spawned at position + shooting\_direction * 50 offset
    \item Projectile added to GameManager.current\_game\_scene.projectile\_parent
    \item Fire cooldown timer starts on shoot, can\_fire set to false
    \item can\_fire becomes true when fire\_cooldown\_timer times out
    \item Firerate power-up bypass allows rapid-fire without waiting for timer
\end{itemize}

\textbf{Power-up System:}
\begin{itemize}
    \item player.power\_up(power\_type, duration) called when power-up collides
    \item Resets any active power-up via reset\_powerup()
    \item Three active power types: ``firerate'', ``speed'', ``shield''
    \item Firerate: Sets firerate\_up=true, changes sprite textures to powered version
    \item Speed: Sets speed\_mult=2, modulates player color to GREEN\_YELLOW
    \item Shield: Sets shield\_up=true, shows shield\_sprite
    \item Powerup\_bar ProgressBar displays time\_left with colored background
    \item On powerup\_timer timeout, reset\_powerup() called to clear effects
    \item Reset restores original sprites, removes color modulation, hides shield
\end{itemize}

\textbf{Health and Damage:}
\begin{itemize}
    \item damage(dmg) called when projectile collides with player
    \item If shield\_up true, damage is negated (early return)
    \item Otherwise health -= dmg
    \item health\_bar.value updated to current health
    \item When health $\leq$ 0, die() called which:
    \begin{itemize}
        \item Calls GameManager.game\_lost()
        \item Queues player for deletion
    \end{itemize}
\end{itemize}

\textbf{Input Blocking:}
\begin{itemize}
    \item check\_input\_blocked() evaluated in \_input() and \_physics\_process()
    \item Returns true if: dead flag set, GameManager.game\_ended true, or pause menu visible
    \item Prevents input processing during pause or after game ends
    \item Movement sprite set to idle if input blocked
\end{itemize}

\subsubsection{Enemy System Details}

The Enemy class is a CharacterBody2D with async shooting loop:

\textbf{Initialization:}
\begin{itemize}
    \item Cooldown Timer configured with random wait\_time (1-4 seconds)
    \item row\_offset assigned by EnemyManager after instantiation
    \item Position set by EnemyManager via add\_enemy() and modulo placement
    \item \_Engage() coroutine started in \_ready()
\end{itemize}

\textbf{Shooting Loop (\_Engage Coroutine):}
\begin{itemize}
    \item Infinite while loop: ``while health > 0''
    \item Await cooldown\_timer.timeout
    \item If \_will\_shoot() (50\% RNG) AND not raycast.is\_colliding():
    \begin{itemize}
        \item Call \_shoot() to create and fire projectile
        \item Set new cooldown\_timer.wait\_time to random 1-4 seconds
    \end{itemize}
    \item Restart cooldown\_timer
    \item Loop continues until health $\leq$ 0
\end{itemize}

\textbf{Obstruction Detection (RayCast2D Node):}
\begin{itemize}
    \item Each Enemy ship has a RayCast2D child node with target\_position = Vector2(0, 60)
    \item Raycast points downward matching shooting direction
    \item Collision checked via raycast.is\_colliding() inline in shooting loop
    \item Eliminates manual PhysicsRayQueryParameters2D construction per shot
    \item Higher performance as RayCast2D is managed by Godot's physics server internally
    \item Prevents shooting through other enemies or obstacles
\end{itemize}

\textbf{Damage and Death:}
\begin{itemize}
    \item damage(dmg) called by projectile on collision
    \item health -= dmg
    \item When health $\leq$ 0, \_die() called:
    \begin{itemize}
        \item \_drop\_power\_up(): RNG check with power\_up\_chance (10\%)
        \begin{itemize}
            \item If true: PowerupManager.Instance.get\_power\_rand\_up() returns random powerup scene
            \item Instantiate powerup and add to projectile\_parent
            \item Set powerup position to enemy position
        \end{itemize}
        \item ScoreManager.add\_points(points) adds 100 to score
        \item GameManager.enemy\_manager.decrement\_enemy\_count()
        \begin{itemize}
            \item number\_of\_enemies -= 1
            \item If $\leq$ 0, call GameManager.game\_won()
        \end{itemize}
        \item queue\_free() removes enemy from scene
    \end{itemize}
\end{itemize}

\subsubsection{Enemy Parent System (Group Movement)}

EnemyParent is a Node2D attached to the Enemy Parent node, controlling random group-level movement of all enemies:

\textbf{Initialization:}
\begin{itemize}
    \item Move Timer started in \_ready() with initial wait
    \item current\_pos tracks virtual grid position (starts at Vector2.ZERO)
    \item move\_step set to row\_offset from EnemyManager
    \item First movement triggered after initial timer timeout
\end{itemize}

\textbf{Direction Decision (decide\_on\_dir):}
\begin{itemize}
    \item Dynamically builds available direction arrays based on current\_pos limits
    \item x\_dir\_array: RIGHT if current\_pos.x $<$ dir\_move\_limit, LEFT if $>$ -dir\_move\_limit
    \item y\_dir\_array: UP if current\_pos.y $>$ -dir\_move\_limit, DOWN if $<$ dir\_move\_limit
    \item Movement bounds: dir\_move\_limit = 2 steps from origin in any axis
    \item 75\% chance of diagonal movement (x + y), 25\% single-axis movement
\end{itemize}

\textbf{Group Movement Loop (move\_enemies):}
\begin{itemize}
    \item Runs while enemy\_manager.number\_of\_enemies $>$ 0
    \item Awaits move\_timer.timeout, then calls decide\_on\_dir() for next direction
    \item Updates current\_pos with chosen direction
    \item Sets move\_timer.wait\_time to random range (2-4 seconds)
    \item Animates via create\_tween().tween\_property() to target position over 1.0 second
    \item All enemies move as a unit since they are children of the Enemy Parent node
\end{itemize}

\subsubsection{Score Manager System Details}

ScoreManager is a global singleton tracking all scoring:

\textbf{Score Accumulation:}
\begin{itemize}
    \item current\_score starts at 0 each level
    \item add\_points(score) called on enemy death from Enemy.\_die()
    \item Enemy.points = 100 by default (configurable per enemy)
    \item current\_score accumulated until level end
\end{itemize}

\textbf{Level End Calculation:}
\begin{itemize}
    \item calculate\_level\_score(survived, time, level) called when game ends
    \item survived parameter: true if all enemies defeated before timer
    \item time parameter: level\_timer.time\_left remaining time
    \item Calculates three components:
    \begin{enumerate}
        \item enemy\_result = current\_score (accumulated kills)
        \item survived\_result = survived\_bonus (1000) if survived else 0
        \item time\_result = clampi((time / level.expected\_time) * time\_bonus, 0, max)
        \begin{itemize}
            \item time\_bonus = 10000 base value
            \item Percentage calculated as: actual\_time / expected\_time
            \item Result clamped between 0 and Vector3i.MAX value
            \item If not survived, time\_result = 0
        \end{itemize}
    \end{enumerate}
    \item final\_score = enemy\_result + survived\_result + time\_result
    \item current\_score incremented by bonuses
    \item If current\_score > highest\_score:
    \begin{itemize}
        \item highest\_score updated
        \item GameManager.main\_menu.highest\_score.set\_highest\_score() called to update UI
    \end{itemize}
\end{itemize}

\textbf{Score Reset:}
\begin{itemize}
    \item reset\_current\_score() called after level end popup closes
    \item current\_score reset to 0 for next level
    \item highest\_score persists across levels
\end{itemize}

\textbf{ScoreData Class:}
\begin{itemize}
    \item Immutable data class returned by calculate\_level\_score()
    \item Fields: enemy (kill points), survived (bonus), time (time bonus), total (final)
    \item Used by EndGamePopup to display score breakdown
\end{itemize}

\subsubsection{GUI System Details}

\textbf{HUD Layer (HUD.gd):}
\begin{itemize}
    \item Canvas layer containing all in-game UI
    \item Sets GameManager.current\_hud in \_init()
    \item Manages pause\_menu and game\_end\_popup visibility
    \item \_input() listens for Menu action to toggle pause
    \item Pause toggle: 
    \begin{itemize}
        \item Toggles pause\_menu.visible
        \item Calls GameManager.slow\_time\_scale() or normal\_time\_scale()
        \item Engine.time\_scale changed to 0.1 or 1.0
    \end{itemize}
    \item Pause blocked when game\_ended flag true
\end{itemize}

\textbf{Level Timer Display (level\_timer.gd):}
\begin{itemize}
    \item Reads GameManager.current\_game\_scene.level\_timer.time\_left each frame
    \item Displays in ``\%05.2f'' format (e.g., ``123.45'')
    \item Color feedback:
    \begin{itemize}
        \item WHITE while time\_left $>$ 0 (bonus available)
        \item RED when time\_left $\leq$ 0 (bonus lost)
    \end{itemize}
    \item On timeout (time\_left $\leq$ 0):
    \begin{itemize}
        \item lost\_bonus\_label becomes visible
        \item bonus\_label hidden
        \item time\_label shows ``00.00''
    \end{itemize}
\end{itemize}

\textbf{End Game Popup (end\_game\_popup.gd):}
\begin{itemize}
    \item Called via GameManager.game\_won() or game\_lost()
    \item Shows won\_panel or lost\_panel based on victory
    \item Calls ScoreManager.calculate\_level\_score():
    \begin{itemize}
        \item survived = true if won\_panel visible (player won)
        \item time = level\_timer.time\_left
        \item level = current game scene
    \end{itemize}
    \item Displays score breakdown:
    \begin{itemize}
        \item total\_score\_label = score\_result.total
        \item enemy\_points = score\_result.enemy
        \item survived\_points = score\_result.survived
        \item time\_points = score\_result.time
    \end{itemize}
    \item Sets Engine.time\_scale = 0.1 (slow motion effect)
    \item on\_return\_button() restores time scale and returns to main menu
    \item Calls ScoreManager.reset\_current\_score() for next level
\end{itemize}

\textbf{Main Menu (main\_menu.gd):}
\begin{itemize}
    \item Sets GameManager.main\_menu in \_init()
    \item on\_play\_pressed(): SceneLoader.load\_direct(game\_scene)
    \item on\_infinite\_pressed(): SceneLoader.load\_direct(infinite\_scene)
    \item Menu hidden (self.visible=false) when game starts
    \item Displays highest\_score GUI element
    \item HighestScoreGUI updated via set\_highest\_score() from ScoreManager
    \item External link buttons: ``HQ'' opens GitHub organization, ``itch.io'' opens Itch.io page
    \item Decorative right panel (right\_decor.gd): Three animated sprites (Player, Fighter, Invader) moving vertically with random speeds and screen-exit respawn
    \item Exit button behavior:
    \begin{itemize}
        \item Web: text = ``Reset'', calls JavaScriptBridge.eval(``window.location.reload()'')
        \item Desktop: calls get\_tree().quit()
    \end{itemize}
\end{itemize}

\textbf{Top Panel HUD (top\_panel.tscn):}
\begin{itemize}
    \item Displays power-up type legends (firerate/speed/shield icons)
    \item Shows control scheme reference (arrow keys, shoot, ESC menu)
\end{itemize}

\subsubsection{GameManager Orchestration}

GameManager is the central state hub coordinating all systems:

\textbf{References Maintained:}
\begin{itemize}
    \item enemy\_manager: Set by EnemyManager.\_init()
    \item current\_hud: Set by HUD.\_init()
    \item current\_game\_scene: Set by Level.\_init()
    \item main\_menu: Set by MainMenu.\_init()
\end{itemize}

\textbf{Game State:}
\begin{itemize}
    \item game\_ended: Boolean flag indicating win/loss state
    \item Initialized to false in \_ready()
    \item Set to true by game\_won() or game\_lost()
    \item Checked by HUD to block pause during end state
\end{itemize}

\textbf{Victory Flow (game\_won):}
\begin{itemize}
    \item Called by EnemyManager.decrement\_enemy\_count() when count $\leq$ 0
    \item Calls \_end\_game():
    \begin{itemize}
        \item game\_ended = true
        \item pause\_menu.visible = false
        \item level\_timer.paused = true
    \end{itemize}
    \item Calls current\_hud.game\_end\_popup.game\_won()
    \item Popup becomes visible with won\_panel shown
\end{itemize}

\textbf{Defeat Flow (game\_lost):}
\begin{itemize}
    \item Called by Player.die() when health $\leq$ 0
    \item Calls \_end\_game() (same as victory)
    \item Calls current\_hud.game\_end\_popup.game\_lost()
    \item Popup becomes visible with lost\_panel shown
\end{itemize}

\textbf{Time Scale Management:}
\begin{itemize}
    \item slow\_time\_scale(): Sets Engine.time\_scale = 0.1
    \begin{itemize}
        \item Called when pause menu opened
        \item Called when end game popup shown
        \item Game runs at 10\% speed for dramatic effect
    \end{itemize}
    \item normal\_time\_scale(): Sets Engine.time\_scale = 1.0
    \begin{itemize}
        \item Called when pause menu closed
        \item Called when returning to menu from end state
    \end{itemize}
\end{itemize}

\textbf{Menu Return Flow (game\_left):}
\begin{itemize}
    \item Called by EndGamePopup.on\_return\_button()
    \item Hides pause\_menu
    \item Calls normal\_time\_scale() to restore speed
    \item Shows main\_menu (GameManager.main\_menu.visible = true)
    \item Queues current\_game\_scene for deletion (cleanup)
\end{itemize}

\subsubsection{Full Gameplay Interaction Example}

\textbf{Scenario: Enemy Dies and Awards Points}

\begin{enumerate}
    \item Player shoots projectile (calls player.shoot())
    \item Projectile travels and collides with enemy (Area2D body\_entered signal)
    \item Projectile calls enemy.damage(1.0)
    \item Enemy health becomes 0
    \item Enemy.damage() calls \_die():
    \begin{enumerate}
        \item \_drop\_power\_up(): 10\% RNG chance
        \begin{itemize}
            \item If true: Random powerup instantiated and added to scene at enemy position
        \end{itemize}
        \item ScoreManager.add\_points(100) increments current\_score by 100
        \item GameManager.enemy\_manager.decrement\_enemy\_count():
        \begin{itemize}
            \item number\_of\_enemies -= 1
            \item If number\_of\_enemies $\leq$ 0:
            \begin{itemize}
                \item GameManager.game\_won() called
                \item \_end\_game() sets game\_ended=true, pauses timer
                \item game\_end\_popup.game\_won() shows win panel
            \end{itemize}
        \end{itemize}
        \item Enemy queued for deletion
    \end{enumerate}
    \item Level Timer Display (if all enemies dead):
    \begin{itemize}
        \item time\_label still shows remaining time (e.g., ``045.32'')
        \item Time\_result bonus calculated in ScoreManager.calculate\_level\_score()
    \end{itemize}
\end{enumerate}

\textbf{Scenario: Player Collects Power-up}

\begin{enumerate}
    \item Power-up falling toward player
    \item Player and power-up Area2D collide
    \item power-up calls player.power\_up(``speed'', 2.0):
    \begin{enumerate}
        \item reset\_powerup() called first to clear any active power
        \item speed\_mult = 2
        \item Player sprite color modulated to GREEN\_YELLOW
        \item powerup\_bar visible and max\_value set to 2.0
        \item powerup\_timer.wait\_time = 2.0, starts
    \end{enumerate}
    \item During power duration:
    \begin{itemize}
        \item \_process() updates powerup\_bar.value = powerup\_timer.time\_left
        \item Player movement x velocity multiplied by speed\_mult=2
        \item Sprite remains powered until timeout
    \end{itemize}
    \item On powerup\_timer.timeout:
    \begin{itemize}
        \item on\_powerup\_timeout() calls reset\_powerup()
        \item speed\_mult = 1
        \item Color modulation restored to WHITE
        \item powerup\_bar hidden
    \end{itemize}
\end{enumerate}

\textbf{Scenario: Pause Menu Interaction}

\begin{enumerate}
    \item Player presses Menu input action during gameplay
    \item HUD.\_input() detects ``Menu'' action
    \item toggle\_menu():
    \begin{itemize}
        \item pause\_menu.visible = true
        \item GameManager.slow\_time\_scale() sets Engine.time\_scale = 0.1
        \item All game processes slow to 10\%
        \item Level timer slows
        \item Enemy cooldown timers slow
        \item Player movement input still processed but slow
    \end{itemize}
    \item Player presses Resume button
    \item HUD.on\_resume\_button() calls toggle\_menu():
    \begin{itemize}
        \item pause\_menu.visible = false
        \item GameManager.normal\_time\_scale() sets Engine.time\_scale = 1.0
        \item Game resumes at normal speed
    \end{itemize}
\end{enumerate}
